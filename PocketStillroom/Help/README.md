# Pocket Stillroom help

Keep a copy of these guides outside the iPhone app so they remain readable if the app expires or cannot open. Start with [Setup](Setup.md), then [Import and offline listening](UseAndImport.md). Read [Refresh, backup and recovery](RefreshAndRecovery.md) before making the phone your only copy of music. Use [I’m stuck](Troubleshooting.md) for common failures.

- **Refresh** renews a signed app’s permission to run. It does not save songs or install a new Pocket Stillroom version.
- **Backup** saves music and library information outside the app. It does not extend signing expiry.

[HelpContent.json](HelpContent.json) supplies the in-app help. [Videos.json](Videos.json) contains optional, currently empty video slots with written fallbacks. Keep recordings, screenshots and reports free of accounts, signing material, device identifiers and private library information.

Begin transfer and recovery checks with a small sample collection. A whole desktop application folder is not a library bundle and can contain accounts or other private data. The source README describes validation scope; these instructions do not establish phone reliability, signing refresh or recovery on a particular device.
